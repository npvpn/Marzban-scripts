# Установка панели партнерского бота на отдельный сервер

## Подготовка (вручную)

1. Привяжите домен к серверу партнера (A/AAAA на IP сервера).
2. В админ-панели бота (супер-админ) → **Администраторы** → создайте администратора:
   - логин;
   - пароль для входа в админку партнера.
3. **Боты** → добавить бота: username, публичное название, API-токен, включить **Внешний Marzban**, указать домен, **MySQL пароль Marzban**, привязать администратора.
4. В списке ботов нажать **Присоединить панель** (иконка цепочки) и скопировать готовую команду `install-partner`.
5. (Опционально, для деплоя панели через GitHub Actions.) Возьмите **registration token** раннера:
   **npvpn/telegram_bot** → Settings → Actions → Runners → **New self-hosted runner** (Linux x64).  
   Токен живёт ~1 час. Метка раннера будет `partner-<bot-telegram>` (например бот `my_vpn_bot` → `partner-my_vpn_bot`).

## Установка панели на сервере (автоматически)

Скрипт выполняет: проверку DNS, настройку UFW (22, 80, 443, 8443, порт панели, **3306 только с IP сервера бота**, если передан `--bot-server-ip`), certbot, установку Marzban с MySQL, SSL, порт 8001, создание админа панели.
В конце (если передан `--token`) ставит self-hosted GitHub Actions runner для выката образа `npvpn/panel`.

Готовую команду лучше брать из админки (**Боты** → Присоединить панель). Ниже — ручной шаблон.

### Интерактивный режим

```bash
sudo bash -c "$(curl -sL https://github.com/npvpn/Marzban-scripts/raw/master/marzban.sh)" @ install-partner
```

Скрипт по очереди спросит: домен, email для Let's Encrypt, MySQL-пароль, логин админа, хэш пароля, название подписки, Telegram поддержки (можно пустым) и бота, **токен runner** (можно оставить пустым и поставить runner позже), **публичный IP сервера бота** (платформа, для доступа Grafana к MySQL панели; можно пустым).

### Неинтерактивный режим

```bash
sudo bash -c "$(curl -sL https://github.com/npvpn/Marzban-scripts/raw/master/marzban.sh)" @ install-partner \
  --domain z2vpn.npvpn.net \
  --cert-email admin@example.com \
  --mysql-password 'YOUR_MYSQL_PASSWORD' \
  --admin-username partner_admin \
  --admin-password-hash '$argon2id$...' \
  --subscription-title 'My VPN' \
  --bot-telegram my_vpn_bot \
  --token 'AXXXXXXXXXXXXXXXXXXXXXXXXXXXXX' \
  --bot-server-ip 1.1.1.1 \
  --non-interactive
```

`--support-telegram` необязателен. `--admin-username` — логин администратора бота (тот же, которым платформа ходит в API панели), `--bot-telegram` — username бота. Команда из админки подставляет `--bot-server-ip` из `BOT_SERVER_IP` или DNS `DOMAIN`.

Параметры runner:

| Параметр | Смысл |
|----------|--------|
| `--token` | Registration token GitHub Actions runner (репа `telegram_bot`) |
| `--project-dir` | Каталог панели для `PROJECT_DIR` раннера (по умолчанию `/opt/marzban`) |
| `--skip-runner` | Не ставить runner (даже если есть `--token`) |

Метка runner **не задаётся вручную**: берётся из `--bot-telegram` → `partner-<username>` (без `@`).

Опционально (панель): `--database mysql|mariadb`, `--version v0.5.2`, `--dev`, `--uvicorn-port 8001`, `--skip-dns-check`, `--skip-cert`, `--skip-firewall`, `--no-logs`.

**`--bot-server-ip`** — публичный IPv4 сервера, где работает бот (платформа). Скрипт откроет в UFW порт `3306/tcp` **только для этого IP**, чтобы Grafana на платформе могла читать MySQL панели. Не открывайте 3306 для всего интернета вручную.

После установки панель доступна по адресу: `https://<домен>:8001/dashboard/`

SSL: том `/etc/letsencrypt:/etc/letsencrypt:ro` и certbot deploy-hook `restart-marzban.sh` (рестарт панели после renew — Uvicorn не перечитывает cert на лету). На старых панелях: `marzban update`.

### Только runner (если панель уже стоит)

Отдельный скрипт — без переустановки панели:

```bash
sudo bash -c "$(curl -sL https://github.com/npvpn/Marzban-scripts/raw/master/install-partner-runner.sh)" @ \
  --token 'AXXXXXXXXXXXXXXXXXXXXXXXXXXXXX' \
  --label partner-my_vpn_bot \
  --project-dir /opt/marzban
```

`--label` обязателен и должен совпадать с тем, что потом укажете в `deploy-partner-panels.yml` / Run workflow.  
Обычно: `partner-` + username бота из `--bot-telegram`.

Опции: `--force` (переконфигурировать), `--name`, `--user deploy`, `--repo-url`, `--skip-service`.

После установки runner: в GitHub → Settings → Actions → Runners статус **Idle**, видна метка.

Дальше в приватном репо `telegram_bot` добавьте метку в [`.github/workflows/deploy-partner-panels.yml`](https://github.com/npvpn/telegram_bot/blob/master/.github/workflows/deploy-partner-panels.yml) (`options` + `ALL_PARTNERS`) и задеплойте через Actions → **Deploy partner panels**. Подробнее: [docs/deploy.md (Partner panels)](https://github.com/npvpn/telegram_bot/blob/master/docs/deploy.md#partner-panels).

## Настройка в админке бота (вручную)

1. **Боты** → добавить бота: username, публичное название, API-токен, домен партнерского сервера, MySQL пароль, привязать администратора.
2. **Присоединить панель** — скопировать команду, установить панель на сервер, затем в модалке нажать **Присоединиться**.
3. **Настройки ботов** → включить нужные модули.
4. Разделы платёжных систем с пометкой **(per-bot)** — настроить оплату для бота.
5. Выйти из супер-админа (**Logout**) и войти под логином/паролем партнера (обычный пароль, не хэш).

## Настройка тестовой ЮKassa

1. В ЮKassa возьмите свободный тестовый магазин.
2. В админке под главным админом → настройки ЮKassa для партнеров.
3. Создайте кассу для партнера:
   - Provider token = 1234
   - vat code = 1
   - external = true
   - recurrent = по необходимости
   - api_token, shop_id — из ЮKassa
4. В ЮKassa в HTTP-уведомлениях укажите URL:

   `https://host.npvpn.net/payments/yookassa/{bot_id}`

   `bot_id` — из раздела **Боты** в админке.
